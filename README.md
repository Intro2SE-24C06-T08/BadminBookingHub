# BadminBookingHub

A university Software Engineering project to design and develop a badminton court booking and management system. The repository currently contains project folder placeholders; application behavior and implementation choices have not yet been established.

## Problem and motivation

Players need a dependable way to find court availability and arrange a booking, while court operators need a clear way to manage courts and reservations. This project will explore how software can make those tasks easier and reduce scheduling conflicts. These are project goals, not claims about implemented functionality.

## Objectives

- Elicit and document user and system requirements.
- Design a maintainable booking and court management system.
- Implement and evaluate the agreed functionality as a team.
- Apply collaborative development, testing, review, and documentation practices.

## Target users and planned capabilities

Intended user groups are badminton players/customers and court operators/administrators. Candidate capabilities include viewing courts and availability, requesting or managing reservations, and maintaining court information. The feature set and rules (including payment, cancellation, and account handling) are TBD and require requirements agreement. No application features are implemented in this repository yet.
